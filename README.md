# LE FUSIL redesign concept

Open `index.html` with VS Code Live Server. The site is a demonstration frontend catalogue only: no payments, checkout, weapon delivery, or backend submission is implemented.

## Image handoff

Add licensed high-resolution files in `assets/images/` for the hero, six categories, six products, showroom, about page, and service backgrounds. Existing CSS fallbacks preserve the complete visual layout until photography is approved.
