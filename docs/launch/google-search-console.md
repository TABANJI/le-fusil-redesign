# Google Search Console launch procedure

No property, verification token or sitemap submission has been performed.

1. Add a Domain property for the confirmed production domain.
2. Add the exact DNS TXT verification value supplied by Google; preserve unrelated DNS and keep the TXT after verification.
3. Verify the production sitemap URL and submit it once.
4. Use URL Inspection for Homepage, Collection and two or three representative Product URLs.
5. Request indexing only for the core pages; do not manually submit every catalogue URL.
6. Review Page indexing, HTTPS, selected canonical and structured-data reports.
7. Monitor mobile/Core Web Vitals reports once sufficient field data exists.
8. Investigate canonical or duplicate-language conflicts before resubmitting.

Indexing is not immediate and ranking is not guaranteed. Never commit a verification token until the exact approved token and deployment method are supplied.
