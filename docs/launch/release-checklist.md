# Release checklist

- [ ] Launch audit and browser smoke tests pass.
- [ ] Production configuration is complete without placeholders.
- [ ] Staging migrations and RLS matrix pass.
- [ ] Admin authentication and role checks pass.
- [ ] Public submissions persist through the protected endpoint.
- [ ] Artifact contains no server secrets or local paths.
- [ ] Canonical domain, sitemap, robots and structured data agree.
- [ ] HTTPS, mobile, RTL, PWA update and offline behavior pass.
- [ ] Database/storage backup and rollback owner are confirmed.
- [ ] User explicitly approves production deployment.

No deployment, migration, DNS change, Search Console action or tag is implied by checking repository-only items.
